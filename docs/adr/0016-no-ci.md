# ADR-0016: No continuous integration

- Status: Accepted
- Date: 2026-10-21

## Context

The repository was set up with a GitHub Actions workflow (build, tests, lint, API-contract drift checks, e2e on pull requests, Docker build). It never ran: the project has no remote and is developed and used on one machine.

## Decision

Remove the workflow and every reference to CI. The checks stay as commands that are run locally: `dotnet build`, `dotnet test`, `npm run lint`, `npm run typecheck`, `npm test`, `npm run e2e`. After an API contract change, build the API and run `npm run api:generate`, then commit both generated files.

This supersedes the CI parts of ADR-0010, ADR-0012 and ADR-0014, which carry dated notes. ADR-0011 only loses the remark that CI reads `.nvmrc`.

## Consequences

- Nothing enforces the checks or catches contract drift automatically; they depend on being run before a commit.
- Less to maintain. If the project gets a remote, a workflow can be added again with a new ADR.
